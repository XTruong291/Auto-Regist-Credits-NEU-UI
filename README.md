# NEU Registration UI

React/Vite dashboard for the NEU course registration backend.

## Local

```bash
npm install
npm run dev
```

Default API base URL:

```text
http://localhost:8000
```

Override with:

```bash
VITE_API_BASE_URL=http://localhost:8000 npm run dev
```

## Docker Compose

Run from the backend folder:

```bash
cd ../Auto-Regist-Credits-NEU
docker compose up --build
```

UI:

```text
http://localhost:5173
```
